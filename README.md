# one-liner-laugh-lab

Competition: one line of at most 200 characters that answers a prompt.

```
Prompt: Robot vacuum eats phone charger. Answer: I did not eat the cord; I neutralized an invasive synthetic snake that was siphoning wall power.
```

### What the joke is about
The joke is a domestic machine confession: a robot vacuum takes the prompt completely seriously, framing its disastrous shredding of an expensive phone charging cable as an act of noble domestic defense against a power-draining synthetic reptile.
